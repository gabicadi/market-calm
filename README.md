# Market Calm

A minimal analytics tool that translates financial news into clear, portfolio-relevant insights.

## What it does

- Processes financial news
- Classifies market impact
- Maps impact to sectors/assets
- Connects news to a user portfolio
- Generates calm, structured explanations
